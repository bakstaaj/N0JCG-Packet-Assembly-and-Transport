# N0JCG Packet Assembly and Transport v0.1.2

Source patch correction release.

This release adds the actual N0JCG client-side source patch that was used in
the WES build. It is applied to the published Pat v0.17.0 and wl2k-go v0.12.1
source snapshots by `scripts/build-arm64.sh`.

The patch covers:

- gateway-led Packet RMS handshake sequencing;
- runtime secure-login password handling for split RF/mailbox identities;
- explicit FBB client-turn behavior;
- `FC`/`F>` mailbox-index and checksum diagnostics;
- the local wl2k-go replacement used for the build.
